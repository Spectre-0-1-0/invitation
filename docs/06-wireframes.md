# 06 Wireframe Descriptions

These descriptions guide the layout of the primary screens, focusing on mobile-first hierarchy.

## 1. Landing Page (Home)
- **Hero Section:**
    - Full-screen height (mobile).
    - Background: Blurred, slow-moving collage of memories.
    - Center: Large Serif Heading ("Class of 2025: Our Story") + Subtitle.
    - Bottom Center: Pulsing "Scroll to Explore" arrow.
- **Featured Highlights:**
    - Horizontal scrolling row of the top 5 "featured" memories.
- **Quick Links Grid:**
    - Four large tiles: [Profiles] [Gallery] [Timeline] [Messages].
- **Footer:**
    - Simple "Made with ❤️ for the Class of 2025."

## 2. Senior Profiles Directory
- **Header:** Simple "The Seniors" title with a search bar.
- **Grid:** 2-column (mobile) / 4-column (desktop) grid of circular headshots.
- **Card Content:** Name and Major below the image.
- **Interaction:** Tap to open the full profile page.

## 3. Individual Senior Profile
- **Top:** "Back to People" link.
- **Profile Section:**
    - Large headshot (left on desktop, center on mobile).
    - Large quote in italics (Serif).
    - Major and achievements list.
- **"Appears In" Section:**
    - Grid of memories tagged with this senior's ID.
- **Personal Messages:**
    - Any farewell notes specifically tagged for them.

## 4. Memory Gallery
- **Filters:** Sticky horizontal pill buttons [All] [Candids] [Events] [Milestones].
- **Layout:** Masonry grid of photos/video thumbnails.
- **Card:** Image with a subtle bottom-up gradient and date/title on hover/tap.
- **Lightbox:** Full-screen modal when a memory is tapped, showing full description and "Related People."

## 5. Timeline
- **Layout:** Vertical line down the center (desktop) or left (mobile).
- **Nodes:**
    - Each node has a Year/Month label.
    - Card attached to node with Title, Description, and small thumbnail.
    - Alternating sides on desktop.

## 6. Message Wall
- **Layout:** "Bento Box" or masonry style of text cards.
- **Visual:** Varied card colors (shades of the secondary palette) to look like a physical board.
- **Content:** Short "From [Name]" at the bottom of each card.

## 7. Tribute Page (The Finale)
- **Layout:** Story-telling scroll.
- **Content:**
    - Sections of large text that appear on scroll.
    - Embedded full-width video at the center.
    - Closing statement from the Dean or Class President.
    - Final group photo.
