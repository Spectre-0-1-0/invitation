# Product Roadmap - College Memory Archive

## Version 1.1 - The Engagement Update (Planned)
- **Individual User Profiles**: Allow seniors to log in via Supabase Auth to update their own quotes and social links.
- **Search Optimization**: Implement server-side search for the Gallery and Senior directory.
- **Enhanced Mobile Gestures**: Add swipe-to-dismiss and pinch-to-zoom for the Polaroid view.

## Version 2.0 - The Institution Edition (Long-term)
- **Multi-Class Support**: Ability to host multiple graduating classes on a single instance.
- **Contributor Roles**: Granular permissions (Super Admin, Editor, Contributor).
- **Video Processing**: Automatic transcoding and adaptive bitrate streaming for high-quality archival video.

## Optional Enhancements (Future Ideas)
- **Print Integration**: Export "Yearbook PDF" generated from the digital archive.
- **Interactive Map**: Geographical visualization of where seniors are heading after graduation.
- **Legacy Feed**: "On this day" notifications for alumni engagement.
