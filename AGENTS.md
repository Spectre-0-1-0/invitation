# Agent Instructions

This repository contains the documentation and eventually the source code for the College Memory Archive.

## Build and Test Instructions
V1 is a static Next.js site.

- **Development:** `npm run dev`
- **Build:** `npm run build`
- **Linting:** `npm run lint`

## Coding Conventions
- Strictly use TypeScript.
- Follow the design system in `docs/05-design-system.md`.
- All data must be sourced from `src/data/` JSON files.
